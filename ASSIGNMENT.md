# Итоговая работа Spark

Источник: https://app.simulative.ru/course/34/2183

Построить ETL с Kafka, Spark Structured Streaming и Spark ML для классификации токсичных комментариев:

1. Прочитать CSV с текстами и метками токсичности, отправить записи в Kafka.
2. Декодировать сообщения потока и разобрать JSON по схеме, добавить признаки.
3. Обучить на исторических данных ML pipeline: токенизация, векторизация, логистическая регрессия.
4. Применить модель к потоку комментариев.
5. Посчитать токсичные и нетоксичные предсказания по временным окнам.
6. Записать результат в memory sink, перенести в Pandas и построить график.
7. Предоставить выполненный Jupyter Notebook.

Для воспроизводимости выбран публичный Google Civil Comments (CC0). Выборка, разделение и ограничения описаны в ноутбуке.
